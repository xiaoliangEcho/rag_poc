# GNU binutils 工具集

在 Linux 系统中有大量可用的工具可以帮助你理解和处理目标文件。特别地，GNU binutils 包尤其有帮助，而且可以运行在每个 Linux 平台上。

| 工具 | 作用 |
|---|---|
| `ar` | 创建静态库，插入、删除、列出和提取成员 |
| `strings` | 列出目标文件中所有可打印的字符串 |
| `strip` | 从目标文件中删除符号表信息 |
| `nm` | 列出目标文件的符号表中定义的符号 |
| `size` | 列出目标文件中节的名字和大小 |
| `readelf` | 显示目标文件完整结构，包括 ELF 头中编码的所有信息（含 size 和 nm 的功能） |
| `objdump` | 所有二进制工具之母，能显示目标文件所有信息，最大作用是反汇编 `.text` 节中的二进制指令 |

Linux 还提供 `ldd`：列出一个可执行文件在运行时所需要的共享库。
